# 算法关系图

`visualization/index.html` 是可直接在浏览器打开的离线页面，包含生成时的全部契约和公共头文件源码，不需要网络、前端安装或常驻服务。它是代码库的浏览入口，底层 C++ 库仍然独立 include。

`python tools/build_graph.py` 先调用现有目录校验，再读取 `contracts/*.json`。`template.html`、`graph.css`、`graph.js` 是维护源，`index.html` 是生成产物，请勿手工修改。新增符合现有格式的契约会自动出现；未提供中文别名的资产显示契约名称。

每个节点对应稳定资产 ID。圆点表示算法，方点表示数据表示，菱形表示组合配方。线段树与 Fenwick 在整数区间求和条件下关联为替代；补偿求和已用于几何面积和周长。离线动态连通性的时间树是配方内部实现，不能据其名字推断它使用当前单点赋值线段树，因此不添加这条边。

每对节点只绘制一条连线。对称 `alternative` 去重，`uses`、`composes_into`、`representation_for` 保留源、目标和类型。选中相邻节点或悬停连线可查看所有具体关系；侧栏箭头表达方向，替代用双向箭头。筛选某种关系时，只隐藏该关系；节点仍可独立存在。一跳视图遵从当前搜索、类型和关系筛选。侧栏关联列表展示完整登记关系。

第二批迁入后为 71 个资产、76 对关联。新增 SCC→2-SAT/缩点、FFT→卷积、LU→吸收马尔科夫链、Minkowski 差→平移碰撞等真实组合。拓扑序连接带权与无权 CSR，逆序对配方连接压缩和 Fenwick。节点可选 `display_name` 显示名称；关系的 `condition` 在悬停与详情中展示，标签标记“有条件”。整数/浮点不能默认互换；模板的内核依赖按条件选择。条件文本只是说明，未实现通用组合规则求值。

交互包括节点拖拽、背景平移、滚轮缩放、适应画布、暂停/继续力导向布局、搜索、一跳邻居，以及源码弹窗。键盘可通过目录选择资产；聚焦画布后方向键平移、`+`/`-` 缩放、`0` 适应，`Escape` 取消选择或关闭源码。尊重系统减少动画偏好。布局有限次迭代后停止，重新打开不保留位置。

当前力布局为逐对排斥，每帧 O(V² + E)，面向首批小目录；尚未对数百/数千资产校准性能。大规模扩展前应测量布局和 SVG 渲染成本，再考虑空间树近似、后台布局或 Canvas。图谱不执行算法，不搜索新组合，不证明组合满足时空预算。

生成测试检查关系与目录一致、方向保留、替代去重、孤立节点、未来名称回退、非法关系拒绝、HTML 数据转义和生成产物一致。实际浏览器检查覆盖节点选择、搜索、空结果、关系筛选、一跳视图、源码弹窗、缩放及窄屏布局。

浏览器内嵌预览若不支持本地文件协议，可从项目目录临时启动 `python -m http.server 18765 --bind 127.0.0.1 --directory visualization`，打开 `http://127.0.0.1:18765/index.html`。服务器只提供可视化目录，完成预览后可以关闭；离线 HTML 是持久交付。

2026-10-15 的三个问题组合配方连接长度/数值压缩、线段树与无权 CSR，当前 74 个资产、80 对关联。每条 uses 均对应公共头文件的实际调用；树的三次 BFS 为配方内部遍历，不捏造对 Dijkstra 或 LCA 的依赖。
